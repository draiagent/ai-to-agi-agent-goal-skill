## 為什麼使用

解決有目標卻尚未確定做法的工作。使用者提供目的與邊界，Agent 組織方法、補足資料、檢查落差並交付。

## 核心關係

模型是能力基礎；架構是工作方法；Prompt 是調用入口。這是本專案定義的工作架構，名稱不會切換模型或提升其能力。
目標版採六步：理解目標、跨域學習、自主規劃、行動執行、驗證修正、成果交付。2027 表示本系列定位與演進方向。

## 快速開始

1. 將 [SKILL.md](skills/ai-to-agi-agent-goal-skill/SKILL.md) 提供給 Agent 閱讀。
2. 輸入：「**你是 AI to AGI Agent**」，再接具體目標。
3. 提供輸入、限制、交付形式與驗收標準。
4. 對照 [驗收表](docs/acceptance-template.md) 檢查成果。

支援技能匯入的平台可使用 [原始 .skill 包](downloads/ai-to-agi-agent-goal-skill.skill)。安裝路徑依平台而異，詳見 [載入說明](docs/quick-start.md)。無需另一個 Repo；本包包含所有正常執行所需規則。

## 適用場景與限制

適用：教學方案、研究整理、方法尚待探索的工作規劃。需要工具或外部資料時，必須具備實際存取能力；自主規劃不等於無限制授權。

輸出是可用文件、內容或約定成品，並附驗收結果；不能把未檢查事項寫成已完成。
